# Minecraft Project

## Description
A simple Minecraft project with scripts written in English. You can run the main script or add your own modifications.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/olusyamazurenco-gif/Minecraft.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Minecraft
   ```
3. Run the main script:
   ```bash
   python src/main.py
   ```
